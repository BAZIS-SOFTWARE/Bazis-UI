# Бизнес задачи BazisGUI

BazisGUI предоставляет инженеру рабочее место для проведения CAE-анализа на основе BazisCORE. Его основная бизнес-задача — сокращение времени инженера на подготовку расчёта и интерпретацию результатов.

Непосредственные потребители — инженеры-расчётчики, технологи и исследователи. Бизнес-ценность ниже сформулирована как ожидаемый эффект возможностей решения; количественные показатели экономии не установлены.

## Задачи и практическая ценность

| Бизнес-задача | Как GUI её решает | Практическая ценность |
| --- | --- | --- |
| Подготовить инженерную модель через визуальный интерфейс | Позволяет работать с геометрией и сеткой, выбирать объекты, создавать группы, измерять и просматривать сечения | Упрощает подготовку модели и её визуальную проверку |
| Задать физическую постановку задачи | Предоставляет панели материалов, нагрузок, закреплений, источников тепла, начальных условий и временных параметров | Переводит инженерное описание процесса в расчётные данные |
| Организовать выполнение расчёта | Формирует инструкции, задаёт последовательность расчётных этапов, запускает внешний решатель | Объединяет подготовку и запуск в одном рабочем процессе |
| Оценить поведение модели по результатам | Показывает поля результатов, строит графики и анимации | Помогает исследовать распределение величин и их изменение во времени |
| Адаптировать приложение под специализированные процессы | Поддерживает подключаемые мастера и сценарии операций с геометрией | Позволяет создавать предметные инструменты для конкретных инженерных задач |

Основание: [описание GUI](README.md), [формирование инструкций](GUI/Methods/Comp/GenerateTSF.cs), [запуск расчёта](GUI/Methods/Comp/StartStopConp.cs), [графики результатов](GUI/Methods/Results/CreatePlot.cs), [анимация результатов](GUI/Methods/Results/CreateAnimation.cs), [подключение мастеров](GUI/Methods/Masters/OpenMaster.cs), [сценарии геометрии](GUI/Methods/Script/SaveLoadScript.cs).

## Границы текущих возможностей

Перечисленные сценарии относятся к клиенту `BazisGUI.Win/BazisGUI.Win.csproj`. Отдельный проект `BazisGUI.Avalonia` пока предоставляет загрузку проекта, отображение 3D-сцены и выбор объектов; полный набор сценариев прежнего клиента на него не распространяется. Основание: [главное окно BazisGUI.Avalonia](BazisGUI.Avalonia/Shell/MainWindow.cs).

GUI запускает внешний решатель по настроенному пути. Реализация численного решателя не входит в рассмотренное решение GUI. Основание: [запуск расчёта](GUI/Methods/Comp/StartStopConp.cs).

В текущем CORE формирование инструкций реализовано для тепловой, механической и связанной термомеханической задачи. Химическая ветка в этом пути закомментирована, а полноценная гидродинамическая задача требует расширения контрактов. Поэтому наличие соответствующих панелей или структур данных не следует трактовать как готовый полный цикл расчёта всех физических направлений. Основание: [реализация PreProc](../BazisComponents/BazisCore/PreProc/PreProc.cs), [реестр расхождений CORE](../BazisComponents/BazisCore/Documents/ArchitectureDifferences.md).

## Краткое описание продукта

Рабочее место инженера для подготовки CAE-задач, запуска внешнего решателя и анализа результатов, в том числе тепловых и термомеханических процессов.
